# Candy Loader

![Candy Loader](asset/screenshot.png)

(Project 1 of 60)
A Christmas candy-inspired loading animation built with HTML and CSS without a single line of JavaScript.

## Features
- Pure CSS animation
- Seamless diagonal stripes
- Responsive design using viewport units
- Glossy candy-inspired appearance
- Accessible progress bar
- Reduced motion support
- No JavaScript
- No external dependencies

## CSS Techniques
- CSS custom properties
- CSS Grid
- Repeating linear gradients
- Pseudo-elements
- Aspect ratio
- Keyframe animations
- Media queries
